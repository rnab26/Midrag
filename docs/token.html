🔑 Récupérer un token Midrag

Sans ouvrir les outils développeur, et depuis ton téléphone.

Pourquoi ce détour

Midrag n'accepte les appels à son API que depuis son propre site : la page de planning ne peut donc pas se connecter à ta place. Ce favori, lui, s'exécute dans la page Midrag — il y rejoue la connexion officielle (identifiants, puis code reçu par SMS ou WhatsApp) et t'affiche le token, prêt à coller dans la page de planning.

Rien n'est envoyé ailleurs : les appels partent de ton navigateur vers Midrag, comme quand tu te connectes à la main. Tes identifiants restent dans le navigateur, le token n'est jamais enregistré.

2. L'installer comme favori

Une seule fois. Un favori ne peut pas être créé directement avec ce type d'adresse : on en crée un normal, puis on remplace son adresse.

Sur iPhone (Safari)

  1. Sur n'importe quelle page : bouton Partager → Ajouter un signet → nomme-le Token Midrag → Enregistrer.
  2. Icône Signets (le livre) → Modifier → touche Token Midrag.
  3. Efface l'adresse, colle le code copié à l'étape 1, puis OK.

Sur Android (Chrome)

  1. Sur n'importe quelle page : menu ⋮ → l'étoile pour créer un favori.
  2. Menu ⋮ → Favoris → appui long sur le favori → Modifier.
  3. Nom : Token Midrag. Adresse : colle le code copié à l'étape 1. Enregistre.

3. S'en servir

  1. Ouvre bizn.midrag.co.il (pas besoin d'être déjà connecté).
  2. iPhone : Signets → touche Token Midrag.
    Android : tape Token Midrag dans la barre d'adresse et choisis la suggestion.
  3. Remplis tes identifiants (retenus ensuite), reçois le code, valide : le token s'affiche avec un bouton Copier.
  4. Reviens sur la page de planning, carte Token Midrag, colle et enregistre.
La page de planning vérifie derrière en lançant une exécution de test : tu sais tout de suite si le token est bon.
