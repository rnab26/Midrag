📅 Midrag — planning de disponibilité

Configure quand le bot doit te maintenir "disponible" automatiquement, jour par jour.

Connexion

Le jeton reste uniquement stocké dans ce navigateur (localStorage), jamais envoyé ailleurs qu'à api.github.com.
Comment créer ce jeton ?

GitHub → ton avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Repository access : seulement "Midrag". Permissions : Contents: Read and write (et Actions: Read and write si tu veux le bouton "Lancer maintenant" ci-dessous). Copie le jeton généré et colle-le ici.

Calendrier de disponibilité

Doit rester bien en dessous d'1h (l'expiration de "disponible maintenant"). 15 min laisse une bonne marge.
