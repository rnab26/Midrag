Tu peux ajouter plusieurs créneaux sur une même journée (ex: 10h-14h puis 18h-21h) avec "+ Ajouter un créneau". En dehors des créneaux configurés, le bot ne touche à rien — Midrag applique alors sa propre expiration automatique (voir l'explication dans le chat).

Connexion

Le jeton reste uniquement stocké dans ce navigateur (localStorage), jamais envoyé ailleurs qu'à api.github.com. Ce n'est pas le token Midrag : celui-là se renouvelle par SMS, plus bas.
Comment créer ce jeton ?

GitHub → ton avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Repository access : seulement "Midrag". Permissions, toutes en Read and write : Contents (planning), Secrets (renouvellement du token Midrag), Actions (exécutions), Issues (état du bot) et Workflows (fréquence). Copie le jeton généré et colle-le ici.

Sur un jeton déjà créé, les permissions se modifient sans changer sa valeur : liste des fine-grained tokens → ton jeton → section Repository permissions → Update token.

Plus simple si la liste des permissions te résiste : un jeton classique avec les deux cases repo et workflow couvre tout d'un coup (il commence par ghp_). Contrepartie : il donne accès à tous tes repos, pas seulement Midrag.

En cas de doute, le bouton « Diagnostiquer le jeton » teste chaque permission une par une et dit laquelle manque.

Renouveler le token

Connecte-toi d'abord : menu ☰ → Connexion.

Renouveler le token Midrag

À faire une seule fois. Tes identifiants Midrag sont rangés dans les secrets chiffrés du repo (jamais dans le code). Le jeton GitHub de cette page y est copié aussi, pour que le renouvellement puisse s'écrire tout seul.
Le token dure environ un mois. Touche le bouton : Midrag t'envoie un code par SMS, tu le tapes ici, c'est fini.

Notifications

Connecte-toi d'abord : menu ☰ → Connexion.

Notifications sur ce téléphone

Reçois une notification quand le token Midrag doit être renouvelé (une par jour, à l'heure réglée dans Réglages, pendant les jours qui précèdent l'expiration) ou quand le bot est bloqué. Un seul appareil à la fois : le dernier sur lequel tu les actives.
Pour des notifications fiables, installe l'application : menu Chrome ⋮ → « Installer l'application ».

Réglages

Connecte-toi d'abord : menu ☰ → Connexion.

Réglages

Doit rester bien en dessous d'1h (l'expiration de "disponible maintenant"). 15 min laisse une bonne marge ; 45/60 min laissent moins de marge en cas de délai GitHub.
À partir de ce délai, le bot t'envoie une notification par jour et ouvre une issue d'avertissement — une seule, refermée toute seule dès que le token est renouvelé. Sans ça, tu n'es prévenu qu'une fois la disponibilité déjà tombée.
Heure d'Israël. La notification ne part que si tu as activé les notifications (menu → Notifications).
Le planning est daté jour par jour : quand la dernière date est passée, le bot tourne sans rien repointer. Une issue s'ouvre à l'approche de cette date, et se referme dès que tu remets des créneaux. Un jour réglé sur « Pas disponible » compte comme configuré.
