📅 Midrag — planning de disponibilité

Configure quand le bot doit te maintenir "disponible" automatiquement, jour par jour.

Connexion

Le jeton reste uniquement stocké dans ce navigateur (localStorage), jamais envoyé ailleurs qu'à api.github.com. Ce n'est pas le token Midrag : celui-là se colle plus bas, dans « Renouveler le token Midrag ».
Comment créer ce jeton ?

GitHub → ton avatar → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Repository access : seulement "Midrag". Permissions, toutes en Read and write : Contents (planning), Secrets (renouvellement du token Midrag), Actions (exécutions), Issues (état du bot) et Workflows (fréquence). Copie le jeton généré et colle-le ici.

Sur un jeton déjà créé, les permissions se modifient sans changer sa valeur : liste des fine-grained tokens → ton jeton → section Repository permissions → Update token.

Renouveler le token Midrag

Le token Midrag dure quelques semaines. Quand il expire, le bot s'arrête de lui-même et ouvre une alerte. Colle ici le token frais : il est chiffré dans ce navigateur puis envoyé directement dans le secret GitHub — il n'est jamais écrit dans le repo, ni conservé sur cette page.
Pas de token sous la main ? Récupérer un token depuis ton téléphone — sans outils développeur.
Où trouver ce token ?

Le plus simple, surtout au téléphone : la page de récupération. Elle installe un favori qui rejoue la connexion Midrag (identifiants + code reçu par SMS) directement dans le site, et t'affiche le token.

À la main : connecte-toi sur bizn.midrag.co.il (téléphone + n° d'entreprise + code SMS) avec les outils développeur ouverts (F12) → onglet Network, filtre Fetch/XHR → requête Token → onglet Response → copie la valeur de data.token (elle commence par eyJ). Procédure détaillée dans le README.

Le jeton GitHub ci-dessus doit avoir la permission Secrets: Read and write pour que ce bouton fonctionne, et Issues: Read and write + Actions: Read and write pour l'état ci-dessus.

Calendrier de disponibilité

Tu peux ajouter plusieurs créneaux sur une même journée (ex: 10h-14h puis 18h-21h) avec "+ Ajouter un créneau". En dehors des créneaux configurés, le bot ne touche à rien — Midrag applique alors sa propre expiration automatique (voir l'explication dans le chat).
Doit rester bien en dessous d'1h (l'expiration de "disponible maintenant"). 15 min laisse une bonne marge ; 45/60 min laissent moins de marge en cas de délai GitHub.
À partir de ce délai, le bot ouvre une issue d'avertissement — une seule, refermée toute seule dès que le token est renouvelé. Sans ça, tu n'es prévenu qu'une fois la disponibilité déjà tombée.
